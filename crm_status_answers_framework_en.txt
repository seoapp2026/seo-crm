SECTION 1: THE PRIMARY STATUS FRAMEWORK (WORDPRESS & CRM SCOPE)

1. WHAT WE HAVE (Current System State)
• A fully functional, decoupled SEO CRM powered by FastAPI (Python) and React/Vite.
• Direct WordPress REST API integration using WordPress Application Passwords.
• Live connection testing endpoint (`/api/v1/wordpress/test-connection`).
• Direct 1-Click Page/Post Push engine (`/api/v1/wordpress/push`).
• Full Multi-Format Export Engine:
  - WP All Import CSV (with UTF-8 BOM encoding for seamless Excel/WordPress reading).
  - Rank Math SEO CSV (meta titles, meta descriptions, focus keywords).
  - Hierarchical structure JSON.
  - Formatted individual HTML page files for manual or Divi Builder import.
  - Complete downloadable ZIP bundle.
• AI Layout & HTML Styler ("El Maquetador"): Generates responsive comparison tables, pros/cons boxes, CTA buttons, and FAQ accordions with semantic CSS classes.
• Product Fact Repository (`Product` model) with names, brands, SKUs, features, prices, currencies, and source URLs.

2. WHAT I CAN DO (Immediate User Capabilities)
• Test and verify WordPress credentials with a single click from the CRM.
• Send content drafts directly to WordPress as "Draft" or "Published" pages.
• Automatically populate Rank Math SEO meta titles, meta descriptions, and primary keywords in WordPress without manual copying.
• Download a complete ZIP bundle and import hundreds of pages into WordPress using the "WP All Import" plugin in under 2 minutes.
• Scrape competitor URLs to extract heading structures (H1, H2, H3), word counts, keywords, and comparison tables.
• Generate responsive product comparison tables with badges, ratings, and affiliate CTA links.
• Store verified product facts so the AI never hallucinates pricing or specifications.

3. WHAT I CANNOT DO YET (Current Technical Boundaries)
• Direct Reverse Sync: If you edit a page inside WordPress WP-Admin, the CRM does not automatically pull those edits back into the CRM database in real time.
• Native Direct WooCommerce Product Endpoint: The CRM currently pushes to `/wp-json/wp/v2/pages` and `/wp-json/wp/v2/posts`. It does not yet push directly to `/wp-json/wc/v3/products`.
• Automated WordPress Media Library Image Uploads: Images in content are referenced via external image URLs rather than uploaded to the WordPress media library via `/wp-json/wp/v2/media`.
• Live Remote Plugin Verification: The CRM formats shortcodes and tables (for AAWP or custom affiliate blocks), but does not verify if the AAWP plugin license is active on your server.

4. HOW I WOULD WORK (Step-by-Step Daily Workflow for a Non-Technical User)
• STEP 1 (Inside CRM): Create your Project and enter your WordPress URL, Username, and Application Password.
• STEP 2 (Inside CRM): Enter target keywords or run an automated research scan to create page outlines.
• STEP 3 (Inside CRM): Click "Generate Draft / Layout". The AI Maquetador generates the complete article, headings, comparison tables, pros/cons boxes, and Rank Math SEO tags.
• STEP 4 (Inside CRM): Review the visual preview. If satisfied, click "Push to WordPress".
• STEP 5 (Inside WordPress): The CRM instantly creates the page as a "Draft" in your WordPress admin with Rank Math fields already filled.
• STEP 6 (Inside WordPress): Log into WordPress, open the draft, give it a quick visual check, add any private affiliate images if needed, and hit "Publish".

5. WHAT REMAINS PREPARED FOR LATER (Ready for Activation in Next Phases)
• Direct WooCommerce product creation and inventory updates.
• Webhook listeners (`/api/v1/webhooks/wordpress`) for automatic bidirectional status updates.
• Notion synchronization for high-level editorial calendar planning and task tracking.
• Make / n8n automation scenarios for automated scheduling and multi-channel posting.

SECTION 2: THE COMPETITOR & AUDIT TRACKING FRAMEWORK

This framework tracks both business outcomes and CRM operational activity:

1. WHAT WAS DONE (CRM Internal Actions):
   - Specific scraping tasks executed, competitor URLs scanned, keyword clusters built, and drafts pushed to WordPress.
   - Distinctly logged in `ResearchJobs`, `SyncJobs`, `ContentDrafts`, and `Notes`.

2. WHAT WAS DISCOVERED (Market & Competitor Insights):
   - Competitor strengths, weaknesses, heading hierarchies, missing content clusters, and keyword search volumes.
   - Extracted automatically via `competitor_scraper_service.py` and DataForSEO research.

3. WHAT WAS CHANGED (Optimizations & Content Updates):
   - New pages created, existing titles/meta rewritten, comparison tables updated, and internal links established.

4. WHAT RESULT IT PRODUCED (SEO & Business Performance):
   - Measured cleanly through Google Search Console (`GscData`) and Google Analytics (`AnalyticsData`):
     • Impressions, Clicks, Click-Through Rate (CTR), Average Position.
     • Sessions, Engaged Users, Bounce Rate, and Affiliate Conversions / Revenue.

5. WHAT IS MISSING (Identified Gaps):
   - Unranked keywords, competitors with higher backlink counts, or missing comparison tables stored in `ResearchOpportunities` and `ResearchLinkGaps`.

6. NEXT ACTION (Actionable Next Step):
   - Prioritized task generated for the user (e.g. "Create TSG comparison guide for Keyword X" or "Push 3 reviewed drafts to WordPress").

SECTION 3: THE NOTION & AUTOMATION INTEGRATION FRAMEWORK

CORE PRINCIPLE: [NOTION ORGANIZES / PROPOSES] → [CRM VALIDATES / EXECUTES]

• WHAT NOTION DOES (The Master Organization & Knowledge Hub):
  - Organizes active projects, daily agenda, editorial calendars, and task assignments.
  - Houses the Master Prompt Library and versioning history.
  - Receives high-level summaries and weekly performance reports from the CRM.
  - Allows you to set high-level statuses (e.g. "Approved for Publishing", "Needs Revision", "Priority: High").
  - DOES NOT modify database schemas, keyword IDs, scraping algorithms, or technical JSON files.

• WHAT MAKE / N8N DOES (The Middleware Layer):
  - Acts as the secure bridge connecting Notion, CRM, and WordPress.
  - Listens to CRM status events (e.g. "New opportunity found") and creates tasks in Notion.
  - Listens to Notion status changes (e.g. "Content marked Approved") and triggers the CRM WordPress push.

• WHAT CRM DOES (The Operational Data & Execution Engine):
  - Holds the relational database of keywords, SERPs, competitor data, and product facts.
  - Validates all technical parameters before executing pushes.
  - Executes scraping, AI layout generation, and direct API pushes to WordPress.

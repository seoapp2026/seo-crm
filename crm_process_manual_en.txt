CRM SEO — User Manual and How It Works

This document explains, in plain language, how the system works behind the scenes. You don't need to understand programming — only the flow and logic, so you know what each part does and what you need to do yourself.


1. THE BIG PICTURE

The system organizes your SEO work in a simple structure:

Project → Niche → Page → Keyword → URL

A Project groups your websites. Within each project there are Niches (topics). Within each niche there are Pages (guides, comparisons, reviews). Each page has its assigned Keywords. And each page has a URL with its indexing status.

Everything you do in the system hangs off this structure.


2. WHAT PHASE 1 DOES (ALREADY WORKING)

Phase 1 is the skeleton: where you store and organize all your information.

- You see a general overview on the Dashboard.
- You create and organize Projects, Niches, Pages, Keywords, and URLs.
- The system warns you if you repeat a keyword on two pages (cannibalization).
- You see internal linking and whether there are orphan pages (with no links).
- You generate content drafts with AI based on page type.

In this phase, you enter the information and the system organizes it. Real Google data is not connected yet — that comes in Phase 2.


3. WHAT PHASE 2 ADDS (IN DEVELOPMENT, ~50% COMPLETE)

This is where the system starts pulling real data and using AI in a more advanced way.

3.1 Google connection

The system connects directly to:

- Google Search Console: impressions, clicks, CTR, and real position for each page.
- Google Analytics: traffic and user behavior on your pages.
- Google Ads / Keyword Planner: real search volume for keywords.

This data is saved automatically in the system, linked to each page and each keyword. You don't have to fetch this data by hand — the system brings it in on its own.

3.2 AI assistants

Instead of a single content generator, Phase 2 has several "assistants," each specialized in one task:

SEO Architect
  Proposes which pages and categories to create

Keyword classifier
  Decides which keyword goes on which page and with what priority

Content generator
  Writes content, now using real Google data

Competitor analyst
  Reviews what competitors do and what to improve

Continuous optimizer
  Detects pages that are losing performance and suggests changes

3.3 How everything connects — this is the important part

This is your main question, so we'll go step by step:

You don't have to pass results from one GPT to another by hand. The system does it automatically internally. It works like this:

1. You choose a page or a task (for example: "optimize this page").
2. The system looks on its own, without you doing anything, at what data that task needs (for example, whether Search Console or Analytics data is required) and pulls it from the right place.
3. That data is automatically inserted into the prompt for the right assistant.
4. The AI generates the result.
5. If that task needs a second step (for example, first classify the keyword and then generate the content), the system passes the first assistant's output to the second one automatically.
6. At the end, it shows you the complete result.
7. You review and decide whether to approve it, edit it, or discard it. The system never publishes anything on its own.

All of this happens with a single click from you. No external tool like Make or Zapier is needed — because the system is custom-built, that chain of steps is already built into the application itself.

3.4 Performance dashboard

A screen where you see at a glance which pages are doing well and which need work, based on real data from Google.

3.5 Prompts are editable

Each assistant has its prompt stored in the system (it isn't hard-coded). That means if later you want to change how an assistant writes or what it prioritizes, you edit the prompt text without having to rebuild the application.


4. END-TO-END FLOW

Google (real data)
  ↓
The system saves the data on the matching page/keyword
  ↓
You choose a task (e.g. "optimize this page")
  ↓
The system picks the right prompt(s) and injects the data automatically
  ↓
The AI generates the result (one step or several chained together)
  ↓
You review, edit if needed, and approve
  ↓
It is published to WordPress


5. FREQUENTLY ASKED QUESTIONS

Do I need Make, Zapier, or something similar?
No. The whole chain of steps is built inside the system itself.

Do I have to tell it manually where to get each piece of data (Analytics or Search Console)?
No — the system already knows what data each assistant needs for each task. If in some case you want to choose manually, that option can be added, but it isn't required for normal use.

Can the system publish on its own without my review?
No. The system is supervised: the AI proposes, you approve. It never publishes anything without your review.

Can I change how an assistant writes later?
Yes, by editing its prompt in the system itself, without touching code or rebuilding anything.

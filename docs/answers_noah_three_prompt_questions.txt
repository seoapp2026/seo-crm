
1) Can I create, save, and edit all these prompts in the Prompt Editor?

Almost. You can edit and save the system prompts of the 5 existing assistants (description, default model, full prompt text). Changes apply on the next run. There is no “create new prompt” button yet, so you cannot freely add 11 separate saved prompts. Practical options now: repurpose/edit the 5 assistants, or paste a custom prompt into Contexto extra when you run one.

2) Can I run each one using the context of the selected page/project automatically?

Yes. When you select a page, niche, or competitor and run an assistant (or Generador), the CRM injects that project/page context (and GSC/GA4 metrics if synced). It does not run over the whole project in the background by itself.

3) Can I manually add the result of the previous prompt as context for the next one?

Yes. Use Contexto extra: paste the previous output (or any notes) before running the next step. There is no automatic chain; you control the sequence manually.

Bottom line: for a manual prompt-by-prompt workflow with review between steps, the current system is enough. No coordinating agent needed right now. Creating a full library of 11 named prompts as separate CRM rows would need a small later enhancement; until then, use the 5 editable assistants + Contexto extra.

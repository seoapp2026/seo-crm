How to use this file
  - Go top to bottom.
  - Mark [ ] when you start, [x] if it works.
  - If something breaks, write FAIL and a short note at the end of the section.
  - Keep the project filter (top bar) on ONE project while you create data.

What you need
  - CRM login email and password
  - (Optional) a Google account with Search Console / Analytics / Ads
    if you want real data
  - A test project (create it in step 4; you can delete it at the end)

4. STRUCTURE (the tree the whole CRM uses)
================================================================================

Project → Niche → Page → Keywords + URL

4.1 Proyectos
  [ ] Create a project (name e.g. “Prueba CRM”)
  [ ] No Search Console URL → cannot save
  [ ] Set Search Console URL (the GSC one; sc-domain:ejemplo.com is also valid)
  [ ] Set GA4 Property ID if you will connect Analytics
  [ ] It appears in the list (Search Console / GA4 columns)
  [ ] Edit works

4.2 Nichos
  [ ] Create a niche under that project (name + topic)
  [ ] State and monetization save
  [ ] Edit OK

4.3 Páginas
  [ ] Create at least 2 pages in the niche
        1) type TSG (guía / guide)
        2) type TSR (comparativa / comparison) or TSA (reseña / review)
  [ ] Title, objective and type save
  [ ] Edit OK

4.4 Palabras clave
  [ ] Add several keywords
  [ ] Assign them to a page (the selector fills niche/project)
  [ ] Intent: informacional / comercial / transaccional
  [ ] Optional note saves
  [ ] Edit and delete one keyword OK
  [ ] The SAME term on TWO different pages:
        → warning in the form while you type it
        → on save, cannibalization toast
        → amber badge “Canibalización” on the row
  Important: Ads and AI read this table. Assign the term to the page.

4.5 URLs
  [ ] Add a slug for a page (e.g. /guia-ejemplo)
  [ ] Index status: indexada / pendiente / no index
  [ ] Edit OK

4.6 Enlazado interno
  [ ] Link page A → page B
  [ ] If a page has no incoming links, the orphan warning appears
  [ ] Self-link → blocked
  [ ] Delete link OK

4.7 Notas
  [ ] Create a project note
  [ ] Edit and delete OK

6. SINCRONIZACIÓN
================================================================================

  [ ] Three jobs: Search Console, Analytics, Ads
  [ ] Each: schedule, Activo, last run, error, next run, records
  [ ] Statuses: En espera / Ejecutando… / OK / Error

GSC and GA4 are daily; Ads is weekly.

9. HOW AI WORKS (read once)
================================================================================

  CRM data (pages, keywords, notes, competitors)
  + Google data if synced
        ↓
  Generador IA or an Assistant
        ↓
  Draft / analysis on screen
        ↓
  You review → copy → publish by hand (WordPress does not publish alone)

Generador IA
  Uses the page (title, type TSG/TSR/TSA), the niche, and that page’s keywords.
  Does not inject GSC/GA4 metrics (the Assistants Content Generator does).

Assistants
  Arquitecto SEO          → niche
  Clasificador            → niche / keywords
  Generador de contenido  → page + GSC/GA4 metrics if synced
  Analista de competencia → competitor
  Optimizador continuo    → page + performance if synced

AI does not publish to WordPress, does not create Ads campaigns, and does not
decide by itself whether two keywords share a page (you review that).

11. AI ASSISTANTS AND PROMPT EDITOR
================================================================================

11.1 Assistants
  [ ] Arquitecto SEO → pick niche → useful output
  [ ] Clasificador → niche
  [ ] Generador de contenido → page
      (different toast if it used GSC/Analytics metrics)
  [ ] Analista → competitor (if none: “Añade competidores primero.”)
  [ ] Optimizador → page (best from Rendimiento: en caída / necesitan trabajo)
  [ ] “Editor de prompts” (top bar) goes to that screen
  [ ] Optional: copy 2–3 lines from Keywords Ads or Análisis SEO
      into “Contexto extra” and re-run the classifier

There is no agent that runs all 5 in a row: you run them one by one.
Between steps you can paste the previous result into Contexto extra.

11.2 Editor de prompts
  [ ] The 5 assistants, each with a default model
  [ ] Edit description, model and system prompt → save
  [ ] The next run uses the new text
  If you try a change, revert it unless you want to leave it.

12. ANÁLISIS SEO AND PRODUCTOS
================================================================================

12.1 Productos (before TSA reviews)
  [ ] Create a product: name, brand, features, price, currency, etc.
  [ ] Toast: AI will only use these facts
  [ ] Empty price = AI must not invent it
  [ ] Edit OK

12.2 Análisis SEO (DataForSEO)
  [ ] Status strip: live ready, or stub (sample data, €0)
  [ ] Caps visible: 3 competitors, 20 seed keywords, monthly budget
  [ ] Project in the filter
  [ ] Site URL  OR  “Proyecto sin web aún”
  [ ] 1–3 competitors and 3–10 seeds (country es / language es)
  [ ] Analizar proyecto → history: Listo (or a readable Error)
  [ ] Estimated cost; “stub” marker if demo
  [ ] Tabs: Informe · Keywords · SERP · Snapshot · Backlinks · Oportunidades
  [ ] Copy report
  [ ] Re-opening the same analysis from history is free (no second charge)
  [ ] A NEW analysis can charge again

DataForSEO brings volume, CPC and Google results. It does not group keywords
by itself: same intent + similar SERP → one page; different intent/SERP →
own page. Volume picks the main keyword, not a URL per variant.

17. IF SOMETHING IS EMPTY OR FAILS
================================================================================

  Connect disabled .......... set GSC URL or GA4 ID on the project
  Ads empty ................. connect Ads, add keywords, run Ads sync
  AI empty or error ......... the page must have keywords
  Sync in error ............. read the error text on the job card
  Analysis always “stub” .... no live credentials yet (sample data)
  Analysis rejected ......... max 3 competitors and 20 seeds
  AI invents a price ........ fill Productos first

In-app guide: menu Ayuda / Guía.

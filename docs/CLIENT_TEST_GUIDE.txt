SEO CRM — Guía de prueba
Para usar y revisar el CRM pantalla a pantalla.
App: https://crmpersonal.es
Fecha: 20 de agosto de 2026

Cómo usar este archivo
  - Ve de arriba abajo.
  - Marca [ ] al empezar, [x] si funciona.
  - Si algo falla, escribe FAIL y una nota corta al final de la sección.
  - El CRM está en español. El filtro de proyecto (barra superior) debe
    estar en UN proyecto mientras creas datos.

Lo que necesitas
  - Email y contraseña de acceso al CRM
  - (Opcional) una cuenta Google con Search Console / Analytics / Ads
    si quieres probar datos reales
  - Un proyecto de prueba (puedes crearlo en el paso 4 y borrarlo al final)

4. ESTRUCTURA (el árbol que usa todo el CRM)
================================================================================

Proyecto → Nicho → Página → Keywords + URL

4.1 Proyectos
  [ ] Crear proyecto (nombre, p. ej. “Prueba CRM”)
  [ ] Sin URL de Search Console → no deja guardar
  [ ] Poner URL de Search Console (la de GSC; también vale sc-domain:ejemplo.com)
  [ ] Poner GA4 Property ID si vas a conectar Analytics
  [ ] Se ve en la lista (columnas Search Console / GA4)
  [ ] Editar funciona

4.2 Nichos
  [ ] Crear nicho en ese proyecto (nombre + tema)
  [ ] Estado y monetización se guardan
  [ ] Editar OK

4.3 Páginas
  [ ] Crear al menos 2 páginas en el nicho
        1) tipo TSG (guía)
        2) tipo TSR (comparativa) o TSA (reseña)
  [ ] Título, objetivo y tipo se guardan
  [ ] Editar OK

4.4 Palabras clave
  [ ] Añadir varias keywords
  [ ] Asignarlas a una página (el selector rellena nicho/proyecto)
  [ ] Intención: informacional / comercial / transaccional
  [ ] Nota opcional se guarda
  [ ] Editar y borrar una keyword OK
  [ ] El mismo término en DOS páginas distintas:
        → aviso en el formulario al escribirlo
        → al guardar, toast de canibalización
        → badge ámbar “Canibalización” en la fila
  Importante: Ads y la IA leen esta tabla. Asigna el término a la página.

4.5 URLs
  [ ] Añadir slug de una página (p. ej. /guia-ejemplo)
  [ ] Indexación: indexada / pendiente / no index
  [ ] Editar OK

4.6 Enlazado interno
  [ ] Enlace de página A → página B
  [ ] Si una página no tiene enlaces entrantes, sale el aviso de huérfanas
  [ ] Enlace a sí misma → bloqueado
  [ ] Borrar enlace OK

4.7 Notas
  [ ] Crear una nota del proyecto
  [ ] Editar y borrar OK

9. CÓMO FUNCIONA LA IA (leer una vez)
================================================================================

  Datos del CRM (páginas, keywords, notas, competidores)
  + datos de Google si hay sync
        ↓
  Generador IA o un Asistente
        ↓
  Borrador / análisis en pantalla
        ↓
  Tú revisas → copias → publicas a mano (WordPress no publica solo)

Generador IA
  Usa la página (título, tipo TSG/TSR/TSA), el nicho y las keywords de esa página.
  No mete métricas GSC/GA4 (eso lo hace el Generador de Contenido de Asistentes).

Asistentes
  Arquitecto SEO          → nicho
  Clasificador            → nicho / keywords
  Generador de contenido  → página + métricas GSC/GA4 si hay sync
  Analista de competencia → competidor
  Optimizador continuo    → página + rendimiento si hay sync

La IA no publica en WordPress, no crea campañas de Ads y no decide sola
si dos keywords van en la misma página (tú lo revisas).

12. ANÁLISIS SEO Y PRODUCTOS
================================================================================

12.1 Productos (antes de reseñas TSA)
  [ ] Crear producto: nombre, marca, características, precio, moneda, etc.
  [ ] Toast: la IA solo usará estos hechos
  [ ] Precio vacío = la IA no debe inventarlo
  [ ] Editar OK

12.2 Análisis SEO (DataForSEO)
  [ ] La franja de estado: live listo, o stub (datos de ejemplo, 0 €)
  [ ] Límites visibles: 3 competidores, 20 keywords semilla, presupuesto del mes
  [ ] Proyecto en el filtro
  [ ] URL del sitio  O  “Proyecto sin web aún”
  [ ] 1–3 competidores y 3–10 semillas (país es / idioma es)
  [ ] Analizar proyecto → historial: Listo (o Error legible)
  [ ] Coste estimado; marca “stub” si es demo
  [ ] Pestañas: Informe · Keywords · SERP · Snapshot · Backlinks · Oportunidades
  [ ] Copiar informe
  [ ] Reabrir el mismo análisis desde el historial = gratis (no cobra otra vez)
  [ ] Un análisis NUEVO sí puede cobrar otra vez

DataForSEO trae volumen, CPC y resultados de Google. No agrupa keywords
solo: misma intención + SERP parecida → una página; intención/SERP distinta
→ página propia. El volumen elige la keyword principal, no una URL por variante.

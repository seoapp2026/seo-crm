================================================================================
GOOGLE ADS DEVELOPER TOKEN - COMPLETE GUIDE
For GOOGLE_ADS_DEVELOPER_TOKEN in .env / Railway
================================================================================


WHAT THIS IS
--------------------------------------------------------------------------------

  - A 22-character code from Google Ads API Center
  - Lives inside a Manager account (MCC), not a normal Ads account
  - NOT the same as: payment card, login password, or GOOGLE_CLIENT_ID
  - One token for your whole CRM app (not one per website)


WHAT YOU NEED BEFORE STARTING
--------------------------------------------------------------------------------

  - A Google account (Gmail or Google Workspace)
  - A working website URL (or GitHub/LinkedIn if you apply as Individual)
  - An email inbox you check every day
  - A regular Google Ads account with payment already set up
    (see docs/google-ads-account-setup.txt if not done yet)
  - 15 to 30 minutes for setup, then days or weeks for Google review


================================================================================
PART A - CREATE A REGULAR GOOGLE ADS ACCOUNT (skip if you already have one)
================================================================================

  1. Open a browser
  2. Go to https://ads.google.com
  3. Sign in with your Google account
  4. Click Start now or Sign up
  5. Enter business name (no URL in the name)
  6. Enter website URL
  7. Complete signup
  8. Add billing / payment:
       - Select billing country
       - Select time zone
       - Create payment profile (Organization or Individual)
       - Click Add payment method
       - Enter card or other method shown
       - Click Submit
  9. Pause any campaign if you do not want to spend:
       - Go to Campaigns
       - Select campaign
       - Set status to Paused

  Copy your Customer ID (needed later):

  1. Stay in Google Ads
  2. Look top-right near your account name
  3. Find the 10-digit number like 123-456-7890
  4. Write it down (this is GOOGLE_ADS_CUSTOMER_ID later)


================================================================================
PART B - CREATE A GOOGLE ADS MANAGER ACCOUNT (MCC)
================================================================================

  You MUST have a Manager account. You cannot get the token from a client account.

  Important Google rule:
    To CREATE a new manager account, use a Google email that has NOT already
    been used for a Google Ads account.

  If your email is already on your Ads account from Part A:
    - Use a different Google email for the Manager, OR
    - Skip this part if you already have a Manager account

  Steps:

  1. Open browser (Incognito helps if switching accounts)
  2. Go to https://ads.google.com/home/tools/manager-accounts/
  3. Click Go to Manager Accounts
  4. Sign in with the Google account for the Manager
  5. Fill the form:
       a. Account name (example: SEO CRM Manager)
          Do not put a URL in the name
       b. Primary use
          Choose Manage my accounts or Manage other people's accounts
       c. Country
       d. Time zone (cannot change later)
       e. Currency
  6. Click Explore your account or Submit
  7. You should be inside a Manager account

  Verify you are in a Manager account:

  1. Look at account name at the top
  2. It should say Manager underneath the name
  3. If it does not say Manager, you are in a client account
     Go back and create or switch to a Manager account


================================================================================
PART C - LINK YOUR ADS ACCOUNT TO THE MANAGER
================================================================================

  From the Manager account - send link request:

  1. Sign in to https://ads.google.com
  2. Select the Manager account (top-left account picker)
  3. Click Accounts icon
  4. Click Sub-account settings
  5. Click blue + button
  6. Click Link existing account
  7. Enter Customer ID from Part A (1234567890 or 123-456-7890)
  8. Click Preview if shown
  9. Click Send request

  From the regular Ads account - accept link:

  1. Sign in to Google Ads
  2. Switch to your regular/client account (not Manager)
  3. Click Admin (wrench icon)
  4. Go to Access and security
     Direct link: https://ads.google.com/aw/accountaccess/users
  5. Click Managers tab
  6. Under Link request, find the Manager account
  7. Click Accept
  8. Confirm on screen if asked

  Confirm link worked:

  1. Sign back into Manager account
  2. Go to Accounts then Sub-account settings
  3. Your client account should appear as linked


================================================================================
PART D - OPEN API CENTER
================================================================================

  1. Open browser
  2. Go to https://ads.google.com/aw/apicenter
  3. Sign in if prompted
  4. Top-left account picker: select Manager account (must say Manager)

  If you see errors:

  "The API Center is only available to manager accounts."
    You are in a client account. Switch to Manager in top-left, reload page.

  "Test account" in red (top-right)
    You are in a test account. Create a real Manager account instead.

  Page asks to sign in
    Sign in with the Google account that owns the Manager.

  If API Center loads:
    You should see API Center with API access / developer token fields.


================================================================================
PART E - APPLY FOR THE DEVELOPER TOKEN (first application)
================================================================================

  1. On API Center page, find API Access form
  2. Fill each field:

     Company name
       Company: your real company name
       Individual: type exactly Individual

     Company / developer URL
       Must be real and working
       Company: your website https://yourcompany.com
       Individual: GitHub or LinkedIn profile URL
       Do NOT use example.com or test.com

     API contact email
       Email you check every day
       Google may email you during review

     Intended use (if asked)
       Example: Internal SEO CRM for keyword volume and competition
       research via Keyword Planner. Internal use only.

  3. Read Terms and Conditions
  4. Check accept box if shown
  5. Click Submit or Apply or Save

  After submitting, check outcome on same page:

  Explorer Access + Approved
    Token works on production, but Keyword Planner APIs are restricted

  Test Account Access + Pending Approval
    Token works only on test accounts until upgraded

  In both cases, copy the Developer token (22 characters) if visible.

  Copy the token:

  1. Find Developer token field on API Center
  2. Copy full 22-character string
  3. Save in password manager
  4. Do not share publicly or commit to GitHub


================================================================================
PART F - APPLY FOR BASIC ACCESS (needed for Keyword Planner in CRM)
================================================================================

  Your CRM needs Keyword Planner data.
  Explorer and Test levels block Keyword Planner APIs.
  You need Basic Access with "Researching keywords and recommendations".

  When to do this:
    After Part E, when any developer token shows in API Center.

  Steps:

  1. Go to https://ads.google.com/aw/apicenter
  2. Sign in
  3. Select Manager account (top-left)
  4. Find Access level on page
  5. Confirm API contact email is correct
  6. Confirm Ads accounts are linked to Manager (Part C)
  7. Click dropdown arrow next to Access level
  8. Click Apply for Basic Access
  9. Fill the form:
       - Use case: keyword research / Keyword Planner
       - Permissible use: Researching keywords and recommendations
       - Tool: internal SEO CRM for volume, competition, CPC
       - Users: internal team
       - URL if asked: your CRM or company site
  10. Submit application
  11. Wait for email or check API Center for updates

  Review time (Google official):
    Basic Access: about 5 business days (can be longer)

  While waiting:
    - Check API contact email daily including spam
    - Reply fast if Google asks questions
    - Do not submit duplicate applications

  When approved:
    - Access level shows Basic Access
    - Status shows Approved
    - Token string may stay the same (you may not get a new one)


================================================================================
PART G - PUT TOKEN IN YOUR CRM
================================================================================

  1. Open Railway project or local backend/.env
  2. Add or update:

     GOOGLE_ADS_DEVELOPER_TOKEN=paste_22_char_token_here
     GOOGLE_ADS_CUSTOMER_ID=paste_customer_id_numbers_only

  3. Customer ID = 10-digit number from Part A (no dashes is fine)
  4. Save
  5. Redeploy or restart Railway service

================================================================================
TROUBLESHOOTING
================================================================================

  API Center says only manager accounts
    Switch to Manager account top-left, reload page

  No token visible after applying
    Refresh page, wait 24 hours, confirm form submitted, confirm correct Manager

  Token is Test Account Access only
    Apply for Basic Access (Part F). Until approved, only test accounts work.

  Token is Explorer Access
    Still apply for Basic Access (Part F). Keyword Planner blocked on Explorer.

  Google emails questions
    Reply within 1-2 business days from API contact email

  Application rejected
    Common: fake URL, example.com, dead website, no reply to Google
    Fix issue and re-apply with valid URL and monitored email

  Same email for Manager and client account
    Google recommends fresh email for new Manager
    Or use existing Manager if you have one


================================================================================
HOW THIS FITS YOUR SEO CRM
================================================================================

  GOOGLE_ADS_DEVELOPER_TOKEN
    Identifies your app to Google
    One for the whole CRM

  GOOGLE_ADS_CUSTOMER_ID
    Identifies which Ads account to query
    One per Ads account in env today

  OAuth Google Ads in Integraciones
    Not fully live yet in the app
    Needs developer token approved first

  Multiple websites later:
    One developer token
    Multiple Ads accounts under Manager
    Each site has its own Customer ID

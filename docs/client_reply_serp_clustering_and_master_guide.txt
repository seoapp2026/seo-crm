1) Grouping keywords vs giving them their own page

That decision is not automated in the CRM. DataForSEO does not decide for you, and the CRM does not compare SERP/URL similarity by itself to say “these keywords go on the same page” or “this one needs its own page”.

What the system already does:

• DataForSEO brings keywords (volume, intent when available, CPC) and Google results (position, title, URL/domain). That is stored and you can see it in the analysis tabs.
• When you assign the same keyword to two pages, the CRM flags Cannibalization. That warning appears after you assign the term; it does not decide the grouping.
• The AI strategy report and the Keyword Classifier can propose clusters, intent, and a target page, but that is the prompt using the data, not an automatic SERP-overlap engine.

Your reading is correct: that decision is made by the prompt (Prompt 3 — clustering + intent in your guide) using the data the CRM already provides. The rule you wrote is the right one:

• same intent + similar Google results → group on one page
• clearly different intent + different SERP → own page
• weak or contradictory signals → manual review

Volume is mainly for choosing the main keyword and the priority. It should not force a new URL for every variant.

In practice: run Análisis SEO → open the Keywords tab and the SERP tab → paste that (or the previous prompt output) into Extra context → run the clustering prompt. You review the result, then create the pages in the CRM.

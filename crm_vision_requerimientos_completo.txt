SECCIÓN 3: MATRIZ DE REQUERIMIENTOS, PREGUNTAS Y ESTRUCTURAS IDENTIFICADAS

3.1. REQUERIMIENTOS DE USABILIDAD Y HERRAMIENTAS RÁPIDAS
• Pestaña / Módulo de "Herramientas / Accesos Rápidos" (Favoritos Profesionales):
  - Organización por Tipo y por Proyecto.
  - Campos requeridos: Nombre de la herramienta + Enlace URL directo + Pequeña nota descriptiva.
  - Herramientas iniciales requeridas:
    • Google Analytics
    • Google Search Console
    • Google Tag Manager
    • Google Trends
    • WordPress (Panel de administración WP-Admin)
    • Panel de Hosting / Servidor
    • Herramientas SEO externas
    • Herramientas de diseño y video (Filmora, Canva, etc.)

3.2. CONTROL, AUDITORÍA Y SEGUIMIENTO DEL CRM
• Histórico y Registro de Trabajo del CRM:
  - Registro claro de: Investigaciones realizadas, competidores analizados, oportunidades detectadas, páginas/keywords/clusters trabajados, mejoras propuestas o ejecutadas y resultados posteriores.
• Gestión de Competencia:
  - Capacidad de mantener 3 competidores activos por proyecto.
  - Biblioteca / Histórico permanente de competidores: permitir rotar competidores activos sin perder el histórico ni los aprendizajes previos.
  - Ficha de Competidor: URL, Nombre, Fecha, Resumen, Fortalezas, Debilidades, Oportunidades, Mejoras detectadas.
  - Análisis On-Demand de URL: Análisis visible de estructura web, tipos de página, blog, reviews, FAQ, CTA, UX, tecnologías detectables.
• Distinción fundamental:
  1. Rendimiento SEO y de Negocio (Tráfico, Posiciones, CTR, Leads, Conversiones, Facturación).
  2. Trabajo realizado por el CRM (Acciones, auditorías, análisis, propuestas y ejecuciones).
• Marco de Seguimiento:
  QUÉ SE HA HECHO → QUÉ SE HA DESCUBIERTO → QUÉ SE HA CAMBIADO → QUÉ RESULTADO HA DADO → QUÉ FALTA → SIGUIENTE ACCIÓN.

3.3. INTEGRACIÓN CON WORDPRESS Y CATÁLOGOS / CONECTORES DE PRODUCTOS
• Marco de explicación requerido (enfoque para usuario no técnico):
  QUÉ TENEMOS → QUÉ PUEDO HACER → QUÉ NO PUEDO HACER → CÓMO TRABAJARÍA YO → QUÉ QUEDA PREPARADO PARA DESPUÉS.
• Aspectos específicos a clarificar:
  - Estado actual de sincronización de contenidos y productos con WordPress (vía REST API / Webhooks / Plugins).
  - Alcance de robots y conectores de productos (investigación, selección, extracción de datos, referencias para plugins como AAWP vs. creación/actualización directa en WP/WooCommerce).
  - Flexibilidad para importar/exportar CSV, JSON, APIs de terceros y compatibilidad con WooCommerce sin rehacer el CRM.

3.4. ARQUITECTURA NOTION <-> CRM <-> MAKE/N8N <-> WORDPRESS
• Rol de cada sistema:
  - CRM: Motor de datos operativos, scraping, análisis SEO, keywords, clusters y ejecución técnica.
  - Notion: Centro maestro de organización visual, conocimiento, toma de decisiones, proyectos, tareas y seguimiento general.
  - Make / n8n: Capa de automatización, intermediación, webhook dispatching y transformación de datos.
  - WordPress: CMS de publicación web y venta/afiliación final.
  - Futuro ERP: Capa extendida de gestión empresarial (clientes, contabilidad, presupuestos, almacén, compras).
• Principio rector de integración:
  "NOTION ORGANIZA / PROPONE → CRM VALIDA / EJECUTA."
  (Notion no modifica campos técnicos críticos, IDs, JSONs puros o métricas crudas de base de datos).
